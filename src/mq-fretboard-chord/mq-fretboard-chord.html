<mq-fretboard-chord>

Fretboard chord diagram. Pass a chord name, get finger positions with open/muted string indicators and barre support. Guitar and ukulele, multiple voicings via position, finger-labels, and left-handed. Ships unstyled — theme the neck via --mq-fretboard-* and the markers via ::part().

← Back to index

Install

npm install @hsablonniere/musiq
import '@hsablonniere/musiq/mq-fretboard-chord';

API

Attributes / Properties

Attribute Property Type Default Description
name name string "" Chord name (e.g. C, Am, Bbmaj7)
instrument instrument 'guitar' | 'ukulele' guitar Target instrument (string count and chord voicings)
position position number 0 Voicing index from the chord database (0 = first)
left-handed leftHanded boolean false Mirror the diagram for left-handed players
finger-labels fingerLabels boolean false Show finger numbers (1–4) on the markers and barres

CSS Parts

Part Description
name Chord name heading above the diagram
marker A fretted note
marker-open Open-string indicator (○) above the nut
marker-muted Muted-string indicator (✕) above the nut
marker-barre A barre spanning several strings at one fret
finger Finger-number label (only with finger-labels)
error Fallback shown for an unknown chord
fret-number Fret-number label (forwarded from mq-fretboard)
