<mq-fretboard>

Fretboard diagram for stringed instruments. Configurable string count and fret range, horizontal or vertical orientation, left-handed flip, inlays, full-neck, and multi-string span slots for barres via extra-slots. Ships unstyled — theme the structure through the --mq-fretboard-* custom properties. Named slots place content on any string/fret position. The component positions, you style.

API

Attributes / Properties

Attribute Property Type Default Description
strings strings number 6 Number of strings (4 = ukulele, 5 = bass, 6 = guitar, …)
start-fret startFret number 1 First fret displayed. When > 1, the nut is replaced by a fret line
end-fret endFret number 12 Last fret displayed
orientation orientation 'horizontal' | 'vertical' horizontal Layout direction of the fretboard
fret-numbers fretNumbers string "" Frets to label: all or a comma-separated list (e.g. 3,5,7,9,12). Empty (default) hides them
inlays inlays boolean false Show position dots at standard frets (3, 5, 7, 9, 12…). Double dot at 12 and 24
full-neck fullNeck boolean false Extend frets and nut edge to edge (instead of string to string)
left-handed leftHanded boolean false Mirror the fretboard for left-handed players
extra-slots extraSlots string "" Comma-separated multi-string span slots (e.g. s1-s6-f5) for barres or capos

Slots

Slot Description
s{N}-marker Before the nut — open-string or muted indicators
s{N}-f{F} Fret F on string N
s{A}-s{B}-f{F} Fret F spanning strings A to B (requires extra-slots)

Basics

Default

Default configuration: 6-string guitar, frets 1–12, horizontal orientation.

Fret numbers

Set fret-numbers="all" to label every fret, or a comma-separated list for specific frets.

fret-numbers="all"

fret-numbers="3,5,7,9,12"

Custom range

Display any fret range. When start-fret > 1, a fret line replaces the nut.

start-fret="5" end-fret="9"

start-fret="1" end-fret="24"

Other instruments

Set the number of strings — ukulele (4), bass (5), guitar (6), 7-string, and so on.

strings="4" (ukulele) — frets 1–7

strings="5" (bass) — frets 1–12

Neck features

Full neck

By default, frets and nut span from the first to the last string. Add full-neck to extend them edge to edge.

string to string (default)

full-neck

Inlays

Position dots at standard frets (3, 5, 7, 9, 12, 15…), double at 12 and 24. Off by default; add the inlays attribute to enable.

without inlays (default)

with inlays

Orientation

Vertical

With orientation="vertical", the neck runs top to bottom and fret numbers move to the left.

E G A C D E A C D E G A E G A C D G A C D E G C D E G A E G A C D E

A minor pentatonic · vertical

Left-handed

Add left-handed to mirror the fretboard. Slotted content stays readable. Works in both orientations.

E G A C A D E G A G C D E G E A C

horizontal · left-handed

E G A A D E G A C D E E A

vertical · left-handed

Slots

Open strings, muted & fretted notes

Place content via named slots: s{string}-f{fret} for fretted notes, s{string}-marker before the nut for open/muted indicators. The component positions, you style. ● = root, ● = scale tone, ○ = open string.

E G A C D E A C D E G A E G A C D G A C D E G C D E G A E G A C D E

A minor pentatonic · full neck

Multi-string spans — barres

Declare span slots via extra-slots="s1-s6-f5" (comma-separated). Each entry creates an s{A}-s{B}-f{F} slot stretching across strings A to B at fret F — barres, capos, or any multi-string element.

A E A D G C

horizontal — barre at fret 5 (strings 1–6)

A E A D G C

vertical — same barre pattern

Style

Custom properties & parts

Theme the structure through the --mq-fretboard-* custom properties and style the fret numbers via ::part(fret-number).
