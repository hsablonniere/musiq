<mq-piano-scale>

Piano keyboard with scale visualization. Pass a scale name, get its notes highlighted across one octave (the tonic repeated at the top). Supports any tonal scale and optional note-labels / degree-labels. Ships unstyled — theme the keyboard, the scale keys, and the tonic via ::part().

API

Attributes / Properties

Attribute Property Type Default Description
name name string — Scale name (e.g. "C major", "A minor pentatonic", "D dorian"). See tonal scale-type for the full list of supported scales
note-labels noteLabels boolean false Show note names on scale keys (English notation: A, B, C, D, E, F, G)
degree-labels degreeLabels boolean false Show scale-degree numbers (1–7) on scale keys; the tonic repeats as 1
mode * mode 'accurate' | 'centered' accurate Black key positioning: accurate uses real piano geometry, centered centers them between white keys

* forwarded to the inner mq-piano.

CSS Custom Properties

Property Type Default Description
--mq-piano-black-key-height * <percentage> 64% Black-key height as a fraction of the full key height: 100% spans the whole keyboard, 0% hides them. Defaults to real piano proportions
--mq-piano-border-color * <color> transparent Base color for all borders (outer + inner)
--mq-piano-border-width * <length> 1px Base width for all borders (outer + inner)
--mq-piano-border-color-outer * <color> falls back to border-color Color of the outer border around the keyboard
--mq-piano-border-color-inner * <color> falls back to border-color Color of borders between keys
--mq-piano-border-width-outer * <length> falls back to border-width Width of the outer border around the keyboard
--mq-piano-border-width-inner * <length> falls back to border-width Width of borders between keys
--mq-piano-border-radius * <length> 0 Corner radius of the keyboard frame; the corner keys are clipped to match (overflow: clip)

* consumed by the inner mq-piano — custom properties inherit through the shadow boundary.

CSS Parts

This component is unstyled. Theme inactive keys with the key-* / note-* parts, and scale keys by combining key-in-scale (and key-tonic for the root) with any of them — ::part() matches an element carrying all the listed names, in any order.

Part Description
name Scale name heading above the keyboard
label Note-name label on a scale key (with note-labels)
degree Scale-degree number on a scale key (with degree-labels)
error Fallback shown for an unknown scale
key * All keys, white and black
key-white * White keys only
key-black * Black keys only
note-c … note-b * White keys by pitch-class, octave-agnostic: note-c, note-d, note-e, note-f, note-g, note-a, note-b
note-cs/note-db … * Black keys by pitch-class, both enharmonic aliases exposed: note-cs/note-db, note-ds/note-eb, note-fs/note-gb, note-gs/note-ab, note-as/note-bb
note-c4, note-fs4 … * A single key by absolute pitch. Black keys expose both enharmonic names: note-cs4/note-db4
key-in-scale Marker covering a key that belongs to the scale. Combine it with any key part: ::part(key-in-scale) (all), ::part(key-white key-in-scale), ::part(key-black key-in-scale), ::part(note-c key-in-scale)
key-tonic Marker covering the tonic — it also carries key-in-scale, so ::part(key-tonic) singles out the root. Declare its rules after key-in-scale to win (source order decides)

* exported from the inner mq-piano (via exportparts).

Style

Scale keys — ::part(key-in-scale)

The marker over each scale note is the part unique to this component. Recolor every scale key with ::part(key-in-scale) (the tonic override rides along).

Single out the tonic — ::part(key-tonic)

Every scale key carries key-in-scale; the tonic carries key-tonic on top. Style key-in-scale first, then key-tonic after it (source order wins — ::part() adds no specificity) to make the root stand out.

Target white, black, or a single note

::part() matches an element carrying all the listed names, so combining key-in-scale with a key part reaches a subset: white vs black, or a single pitch-class.

::part(key-white key-in-scale) · ::part(key-black key-in-scale)

::part(note-c) tints both C · ::part(note-c key-in-scale) underlines the tonic

Labels & degrees — ::part(label) / ::part(degree)

note-labels adds a ::part(label) and degree-labels a ::part(degree) on each scale key — style them independently.

Putting it all together

A fully themed B♭ major (B♭ – C – D – E♭ – F – G – A): dark frame, classic black-and-white keys, green scale markers (a darker shade on the black keys), the tonic B♭ singled out, note names, scale degrees, and a pill heading — every layer reached through ::part().
