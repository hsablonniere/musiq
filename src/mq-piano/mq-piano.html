<mq-piano>

Piano keyboard with realistic key geometry. Configurable range, accurate or centered black key positioning, always locked to real piano proportions. Stylable via ::part() and CSS custom properties. Named slots for per-key annotations.

← Back to index

Install

npm install @hsablonniere/musiq
import '@hsablonniere/musiq/mq-piano';

API

Attributes / Properties

Attribute Property Type Default Description
start-note startNote string C3 First note of the keyboard range. If a black key is specified, the white key before it is included
end-note endNote string E4 Last note of the keyboard range. If a black key is specified, the white key after it is included
mode mode 'accurate' | 'centered' accurate Black key positioning: accurate uses real piano geometry, centered centers them between white keys

The component is always locked to real piano proportions. Set width and/or height on the element to size it (see Dimensions below).

CSS Custom Properties

Property Type Default Description
--mq-piano-border-color <color> #000 Base color for all borders (outer + inner)
--mq-piano-border-width <length> 1px Base width for all borders (outer + inner)
--mq-piano-border-color-outer <color> falls back to border-color Color of the outer border around the keyboard
--mq-piano-border-color-inner <color> falls back to border-color Color of borders between keys
--mq-piano-border-width-outer <length> falls back to border-width Width of the outer border around the keyboard
--mq-piano-border-width-inner <length> falls back to border-width Width of borders between keys

CSS Parts

Part Description
key All keys, white and black
key-white White keys only
key-black Black keys only
note-c … note-b White keys by pitch-class, octave-agnostic: note-c, note-d, note-e, note-f, note-g, note-a, note-b
note-cs/note-db … Black keys by pitch-class, both enharmonic aliases exposed: note-cs/note-db, note-ds/note-eb, note-fs/note-gb, note-gs/note-ab, note-as/note-bb
note-c3, note-fs4 … A single key by absolute pitch (octave-specific). Black keys expose both enharmonic names: note-cs3/note-db3

Slots

Slot Description
note-{name}{octave} Per-note content — e.g. note-C3, note-Fs4, note-Db3. Black keys expose both enharmonic names. Use s for sharp (♯) since # is not valid in slot names.

Range

Default

Without start-note or end-note, the keyboard covers the default range C3 → E4.

Custom

Any start-note / end-note pair — from a couple of octaves to a full acoustic piano. A black key as a bound snaps to include the adjacent white key.

2 octaves · start-note="C3" end-note="C5"

full 88-key piano · start-note="A0" end-note="C8" · 52 white · 36 black

Single bound

Only one end of the range provided, the other is inferred.

start-note="G2" (end inferred)

end-note="G5" (start inferred)

Mode

accurate vs centered

With mode="centered", every white key has the same width and black keys are perfectly centered between their neighbors.

mode="accurate" (default)

mode="centered"

Style

Borders

Width and color via CSS custom properties.

Keys

Style keys by category (::part(key-white) / ::part(key-black)), target a pitch-class octave-wide (::part(note-c), ::part(note-fs), …), or a single key by absolute pitch (::part(note-c3)).

every white key with ::part(key-white) · every black key with ::part(key-black)

every C key with ::part(note-c) · every F♯ key with ::part(note-fs)

Dimensions

The component is a block always locked to real piano proportions (the aspect ratio is derived from the number of white keys). Constrain a single dimension and the other follows the ratio; set both width and height to force an exact box (the ratio is then overridden and keys stretch).

No size set — fills the container width, height from ratio:

fills the available width

Width constrained — height derived:

width: 450px

Height constrained — width derived:

height: 120px · width follows the ratio

Both forced — exact box, ratio overridden:

width: 560px; height: 90px — keys stretch to fill
