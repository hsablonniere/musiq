<mq-fretboard-scale>

Fretboard with scale visualization across the full neck. Pass a scale name and a tuning; every scale note is mapped out, the tonic distinguished. Custom tunings (drop D, ukulele…), configurable fret range, note-labels, degree-labels, left-handed. Ships unstyled — theme the neck via --mq-fretboard-* and the markers via ::part().

Install

npm install @hsablonniere/musiq
import '@hsablonniere/musiq/mq-fretboard-scale';

API

Attributes / Properties

Attribute Property Type Default Description
name name string "" Scale name (e.g. C major, A minor pentatonic, D dorian). Any tonal scale
tuning tuning string E,A,D,G,B,E Open string notes, comma-separated low to high (e.g. D,A,D,G,B,E for drop D)
start-fret startFret number 0 First fret displayed; 0 includes the open strings
end-fret endFret number 12 Last fret displayed
note-labels noteLabels boolean false Show note names on the markers
degree-labels degreeLabels boolean false Show scale-degree numbers on the markers
left-handed leftHanded boolean false Mirror the fretboard for left-handed players
inlays inlays boolean false Show inlay position markers on the neck

CSS Parts

Part Description
name Scale name heading above the fretboard
marker A scale note
marker-tonic The tonic; also carries marker, so ::part(marker-tonic) overrides ::part(marker) when declared after it
label Note-name label (only with note-labels)
degree Scale-degree number (only with degree-labels)
error Fallback shown for an unknown scale
fret-number Fret-number label (forwarded from mq-fretboard)
