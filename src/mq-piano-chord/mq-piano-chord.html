<mq-piano-chord>

Piano keyboard with chord visualization. Pass a chord name, get highlighted keys. Supports inversions via slash chords (C/E, C/G), note-labels, and customizable active color.

← Back to index

Install

npm install @hsablonniere/musiq
import '@hsablonniere/musiq/mq-piano-chord';

API

Attributes / Properties

Attribute Property Type Default Description
chord chord string — Chord name (e.g. "C", "Ebm", "F#maj7"). Supports slash chords for inversions ("C/E")
note-labels noteLabels boolean false Show note names on active keys (English notation: A, B, C, D, E, F, G)

CSS Custom Properties

Property Type Default Description
--mq-piano-chord-active-color <color> #4a90d9 Fill color for active (chord) keys
--mq-piano-black-key-height * <percentage> 64% Black-key height as a fraction of the full key height: 100% spans the whole keyboard, 0% hides them. Defaults to real piano proportions
--mq-piano-border-color * <color> transparent Base color for all borders (outer + inner)
--mq-piano-border-width * <length> 1px Base width for all borders (outer + inner)
--mq-piano-border-color-outer * <color> falls back to border-color Color of the outer border around the keyboard
--mq-piano-border-color-inner * <color> falls back to border-color Color of borders between keys
--mq-piano-border-width-outer * <length> falls back to border-width Width of the outer border around the keyboard
--mq-piano-border-width-inner * <length> falls back to border-width Width of borders between keys
--mq-piano-border-radius * <length> 0 Corner radius of the keyboard frame; the corner keys are clipped to match (overflow: clip)

* consumed by the inner mq-piano — custom properties inherit through the shadow boundary.

CSS Parts

Part Description
title Chord name heading above the keyboard
key * All keys, white and black
key-white * White keys only
key-black * Black keys only
note-c … note-b * White keys by pitch-class, octave-agnostic: note-c, note-d, note-e, note-f, note-g, note-a, note-b
note-cs/note-db … * Black keys by pitch-class, both enharmonic aliases exposed: note-cs/note-db, note-ds/note-eb, note-fs/note-gb, note-gs/note-ab, note-as/note-bb
note-c4, note-fs4 … * A single key by absolute pitch (range C4–B5). Black keys expose both enharmonic names: note-cs4/note-db4

* exported from the inner mq-piano (via exportparts).
