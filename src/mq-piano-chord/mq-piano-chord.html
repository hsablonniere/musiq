<mq-piano-chord>

Piano keyboard with chord visualization. Pass a chord name, get its notes highlighted as pressed keys. Supports inversions via slash chords (C/E, C/G) and note-labels. Ships unstyled — theme the keyboard and the pressed keys via ::part().

API

Attributes / Properties

Attribute Property Type Default Description
name name string — Chord name (e.g. "C", "Ebm", "F#maj7"). Supports slash chords for inversions ("C/E")
note-labels noteLabels boolean false Show note names on pressed keys (English notation: A, B, C, D, E, F, G)
mode * mode 'accurate' | 'centered' accurate Black key positioning: accurate uses real piano geometry, centered centers them between white keys

* forwarded to the inner mq-piano.

CSS Custom Properties

Property Type Default Description
--mq-piano-black-key-height * <percentage> 64% Black-key height as a fraction of the full key height: 100% spans the whole keyboard, 0% hides them. Defaults to real piano proportions
--mq-piano-border-color * <color> transparent Base color for all borders (outer + inner)
--mq-piano-border-width * <length> 1px Base width for all borders (outer + inner)
--mq-piano-border-color-outer * <color> falls back to border-color Color of the outer border around the keyboard
--mq-piano-border-color-inner * <color> falls back to border-color Color of borders between keys
--mq-piano-border-width-outer * <length> falls back to border-width Width of the outer border around the keyboard
--mq-piano-border-width-inner * <length> falls back to border-width Width of borders between keys
--mq-piano-border-radius * <length> 0 Corner radius of the keyboard frame; the corner keys are clipped to match (overflow: clip)

* consumed by the inner mq-piano — custom properties inherit through the shadow boundary.

CSS Parts

This component is unstyled. Theme inactive keys with the key-* / note-* parts, and pressed keys by combining key-pressed with any of them — ::part() matches an element carrying all the listed names, in any order.

Part Description
name Chord name heading above the keyboard
label Note-name label on a pressed key (with note-labels)
error Fallback shown for an unknown chord
key * All keys, white and black
key-white * White keys only
key-black * Black keys only
note-c … note-b * White keys by pitch-class, octave-agnostic: note-c, note-d, note-e, note-f, note-g, note-a, note-b
note-cs/note-db … * Black keys by pitch-class, both enharmonic aliases exposed: note-cs/note-db, note-ds/note-eb, note-fs/note-gb, note-gs/note-ab, note-as/note-bb
note-c4, note-fs4 … * A single key by absolute pitch. Black keys expose both enharmonic names: note-cs4/note-db4
key-pressed Marker covering a key held by the chord. Combine it with any key part: ::part(key-pressed) (all), ::part(key-white key-pressed), ::part(key-black key-pressed), ::part(note-c key-pressed), ::part(note-c4 key-pressed)

* exported from the inner mq-piano (via exportparts).

Style

Pressed keys — ::part(key-pressed)

The marker over each chord note is the one part unique to this component. Recolor every pressed key with ::part(key-pressed).

Target white, black, or a single note

::part() matches an element carrying all the listed names, so combining key-pressed with a key part reaches a subset: white vs black, or a single note.

::part(key-white key-pressed) · ::part(key-black key-pressed)

::part(key-pressed) blue · ::part(note-c) rose on both C · ::part(note-c key-pressed) underlines the pressed one

Chord name — ::part(name)

The chord name above the keyboard is this component's own part, styled independently of the keys — same component, two styles.

Note labels — ::part(label)

With note-labels, each pressed key carries a ::part(label). Print it straight onto the filled key, or turn it into a free-standing dot and leave the keys their own color.

Putting it all together

A fully themed Cm7 (C – E♭ – G – B♭): dark frame, classic black-and-white keys, warm pressed markers (a darker shade on the black keys), the root C singled out, note labels, and a pill heading — every layer reached through ::part().
